# Журнал взаємодії з LLM (log.csv)

Поля: дата, модель/версія, temperature/seed, версія промпту, призначення, сирий вивід (файл), рішення людини.
- Модель: налаштована `claude-sonnet-5-5`; фактична модель субагента може відрізнятися. Температуру й seed у цьому середовищі задати **неможливо**, тому в журналі вказано «не контролювалось» — запуски не відтворюються байт-у-байт.
- `prompts/` — шаблони v1, v2; `in/` — вхідні файли, які бачили генератори (без еталонів); `raw/` — сирі відповіді; `eval_*.json` — розбір кожної відповіді.
- «Рішення людини»: у журналі зазначено рішення автора конвеєра. Перегляд студентом перед здачею потрібен (див. README).
