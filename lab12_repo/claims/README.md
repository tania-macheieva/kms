# Таблиця тверджень (ЛР12)

`claims.csv`: id, твердження, тип (факт/правило/гіпотеза), джерело, рівень верифікації, статус, коментар.
Рівні: V2 — парсер/код/тести/права; V4 — еталонні відповіді та метрики; V1 — джерело (пам'ять моделі без звірки лишається pending); V3 — людина (тут LLM-рецензент, студент має повторити).

Усього 22 тверджень: **verified 13 (59%)**, rejected 2 (9%), pending 7 (32%).
Відхилені: C04 (LLM-операція cube замість rollup) і C05 (зростання черги — артефакт першої версії генератора); пояснення в колонці comment.

## Перелік джерел
- Таксономія ЛР5 (`data/raw/taxonomy_final.csv`, `taxonomy.ttl`); синтетичні дані — `etl/generate.py` (seed 42).
- Документація DuckDB (read-only, `enable_external_access`, `interrupt`), sqlglot; Kimball & Ross (2013); Chaudhuri & Dayal (1997).
- Вихід моделей: `llm_log/raw/`.
