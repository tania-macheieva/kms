# Журнал взаємодії з LLM (log.csv)

Поля: дата, модель/версія, temperature/seed, версія промпту, призначення, сирий вихід, рішення. Модель — налаштована `claude-sonnet-5-5`; фактична могла відрізнятися. Температуру й seed задати неможливо («не контролювалось»), тож запуски не відтворюються байт-у-байт.
`prompts/t2c_v1.txt` — шаблон; `in/` — що бачили генератори (без еталонів); `raw/` — сирі відповіді; `eval_t2c_*.json` — розбір кожної відповіді. «Рішення» — рішення автора конвеєра; перегляд студентом потрібен перед здачею.
