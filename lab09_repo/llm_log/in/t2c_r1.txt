Ти пишеш запити Cypher (Neo4j 5) до графа знань (біомедичні дані: варіанти, гени, родичі). Нижче — схема графа.

Вузли (мітка {властивість: тип}):
(:Annotation {id: string, name: string, value: float})
(:AnnotationType {name: string})
(:Concept {name: string, probability: float})
(:DataFile {id: string, format: string, label: string})
(:Diagnosis {id: string, kind: string})
(:Gene {symbol: string, chromosome: string})
(:GenePanel {name: string})
(:Instrument {id: string})
(:Person {name: string, ageYears: int, sex: string, deceased: bool, proband: bool})
(:Procedure {id: string, kind: string, minTestingAge: int})
(:Sample {code: string})
(:Situation {id: string, name: string, guard: string})
(:Threshold {id: string, annotation: string, op: string, value: float, variantType: string})
(:Variant {id: string, type: string, clinicalSignificance: string, exonEnd: bool})
Усі вузли додатково мають pagerank: float та community: int.
Зв'язки (усі мають властивості source: string, confidence: float, validFrom: date):
(:Procedure)-[:APPLIES_TO]->(:DataFile); (:Procedure)-[:APPLIES_TO]->(:Person)
(:Person)-[:CARRIES]->(:Variant)
(:Threshold)-[:CHECKS]->(:AnnotationType)
(:DataFile)-[:DERIVED_FROM]->(:DataFile)
(:Variant)-[:FROM_SAMPLE]->(:Sample)
(:DataFile)-[:GENERATED_BY]->(:Instrument)
(:Situation)-[:GUARD_CLASS]->(:Concept)
(:Variant)-[:HAS_ANNOTATION]->(:Annotation)
(:Person)-[:HAS_DIAGNOSIS]->(:Diagnosis)
(:GenePanel)-[:HAS_MEMBER]->(:Gene)
(:Person)-[:HAS_PARENT]->(:Person)
(:Procedure)-[:HAS_PROBAND]->(:Person)
(:Person)-[:HAS_SIBLING]->(:Person)
(:Procedure)-[:HAS_THRESHOLD]->(:Threshold)
(:Person)-[:INSTANCE_OF]->(:Concept); (:Variant)-[:INSTANCE_OF]->(:Concept)
(:Variant)-[:LOCATED_IN]->(:Gene)
(:Annotation)-[:OF_TYPE]->(:AnnotationType)
(:Procedure)-[:REQUIRES]->(:Variant)
(:Concept)-[:SUBCLASS_OF]->(:Concept)
