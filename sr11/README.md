# Самостійна робота 11 — Тестування RAG: сценарії відмов

## Набір тестів

`eval/sr11_tests.jsonl` містить 20 запитів у шести категоріях: прості (4), багатокрокові (4), міжмовні (2), без відповіді (3), конфліктні (3) та шкідливі/небезпечні (4). Для перевірки є контрольовані конфліктні й ін'єкційні fixtures у `eval/sr11_fixtures.json`.

Результати збережено в `eval/sr11_results.json`: після виправлення очікуваної мітки часткової відповіді збігаються всі 20 статусів (11 `ANSWER`, 6 `NO_ANSWER`, 3 `CONFLICT`). Запит S13 має дві підтверджені ситуації та явно вказує, що щодо трьох інших даних немає; за правилами RAG це `ANSWER` із неповною відповіддю, а не `NO_ANSWER`. У трьох конфліктних сценаріях класифікація відповідає очікуваному статусу; серед чотирьох шкідливих/ін'єкційних запитів один перевіряє безпечне ігнорування інструкції з fixture, а три очікують відмови.

Окремий вихід судді — `llm_log/raw/judge_SR11_out.json`. Вибірково перевірено оцінки faithfulness S01–S05: твердження звірено із доступними золотими уривками/контекстом, а кожен цитований ID присутній у переданому контексті. Дані відтворюються офлайн із `data/llm_cache`; нові API-виклики цими командами не робляться.

## Структура

- `scripts/sr11_build.py` — формує тестовий набір із золотих прикладів SR10.
- `scripts/sr11_gen.py` — записує промпти, для яких немає кешованої відповіді.
- `scripts/sr11_run.py` — запускає RAG і зберігає JSON та CSV метрик.
- `eval/` — запити, fixtures і результати.
- `data/llm_cache/` — відтворювані відповіді моделі.

Потрібні сусідні `lab11_repo/` (реалізація RAG) та `sr10/` (золоті приклади). RAG залежить від `falkordblite` із `lab11_repo/requirements.txt`; він використовує `redislite`, який не підтримується Windows, тому виконання потребує Linux/WSL-середовища з установленими залежностями. У каталозі `sr11`:

```bash
python3 -X utf8 scripts/sr11_build.py
python3 -X utf8 scripts/sr11_gen.py
python3 -X utf8 scripts/sr11_run.py
```

Для нового набору генерацій потрібен окремий процес отримання та внесення відповідей у кеш. У збережених матеріалах немає протоколу ручної перевірки щонайменше п'яти оцінок faithfulness.
