# Реєстр тверджень (claims.csv)

Поля: `id, claim, type (fact/rule/hypothesis), source, level (V1–V4), status (verified/rejected/pending), comment`.

Рівні: **V1** — поверхнева (одне джерело/інтерпретація), **V2** — виконання, обмеження, повторне обчислення іншим способом, автотест; **V3** — незалежний експерт; **V4** — метрики на незалежних еталонах. V3 і V4 **не досягнуто**: еталони text-to-Cypher і всі запити склала та сама система, що й генерація. Вимога завдання «V4 для метрик text-to-Cypher» виконана лише формально (метрики обчислено на 27 питаннях); чесний рівень — V2.

Частки (22 твердження): verified — 15 (68%), pending — 4 (18%), rejected — 3 (14%). Відхилені: C18 (не Neo4j/GDS), C19 (ролі Neo4j не перевірено), C20 (дані синтетичні). Відкриті: C10, C11, C16, C22.
