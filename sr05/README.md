# Самостійна робота 5 — Порівняння методів побудови таксономій

## Завдання

Побудувати таксономії одного домену двома методами для щонайменше 60 термінів, порівняти їх з еталонною таксономією, обчислити метрики, описати не менше п'яти дефектів і дати рекомендації.

## Файли та результати

- `taxonomies.json` — таксономії у спільному форматі.
- `terms_table.json` — розміщення термінів і порівняння методів.
- `metrics.json` — метрики та чутливість кластеризації.
- `SR5_taxonomy_comparison.xlsx` — таблиці метрик і дефектів.
- `manual_tax.py`, `sr5.py`, `so_parse.py`, `build_out.py` — дані та скрипти.

Збережені результати охоплюють 106 термінів і сім задокументованих дефектів. Таксономія, позначена як ручна, була створена за участю ШІ: її потрібно перевірити й відредагувати самостійно до здачі.

## Відтворення

Для повного повторного запуску `sr5.py` потрібен файл `so.obo`; його немає в цій папці. Залежності — `numpy`, `scikit-learn`, `scipy`, `openpyxl`, `python-docx`.

Таблицю можна перебудувати з PowerShell у цій папці:

```powershell
python -X utf8 build_out.py
```

Скрипт створює також `SR5_report.docx`; якщо запускали його, видаліть цей файл, бо формальний звіт не здається. Залиште XLSX-таблицю.
