# Протокол використання LLM-експерта (ЛР15)

* `log.csv` — дата, модель, параметри, версія промпта, призначення, вхід, файл сирого виходу, рішення людини (`python scripts/make_llm_log.py`).
* `prompts/` — версії промптів агента (`plan_v1/v2`, `draft_naive`, `draft_v1/v2`); `SUBAGENT_BRIEF.md` — єдина інструкція сліпим субагентам.
* `in/<batch>.json` — промпти (system+user), яких не було в replay-кеші; `raw/<batch>.json` — сирі виходи моделі `{key: text}`. `python scripts/llm_batches.py ingest` кладе їх у `llm_cache/` (ключ = sha256(model|system|user)); далі агент працює детерміновано з кешу.
* **Мозок агента:** ключа API немає, тому планувальник і «drafter» — сліпі субагенти (claude-haiku-4-5, як налаштовано); температура/seed недоступні, тож це одна вибірка, а не усереднення. Фактична модель субагента могла відрізнятися від налаштованої.
* **Рівні перевірки тверджень** (`claims/claims.csv`): V1 — відтворюваний скрипт/дані; V2 — тести/SHACL/узгодженість із документами; V3 — експерт-людина (**очікується від студента**; ролі «людини» в цій роботі виконував LLM-асистент); V4 — метрики до/після.
