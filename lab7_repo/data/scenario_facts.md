# Сценарій-даних (синтетичні, вигадані; не містять персональних даних)
Один набір фактів, який кодують в індивідів обидві онтології (моя й чернетка LLM), щоб CQ-запити були порівнянними.

## Родина (усі особи вигадані)
- Olena — пробанд (proband), жінка, 42 роки, має рак молочної залози (breast cancer); має патогенний варіант VAR-001 у гені BRCA1.
- Marta — рідна сестра Oleny, 39 років (родичка першого ступеня).
- Iryna — мати Oleny, 68 років, в анамнезі рак яєчників (ovarian cancer); родичка першого ступеня.
- Petro — батько Oleny, 70 років; родич першого ступеня.
- Sofiia — донька Oleny, 17 років (неповнолітня); родичка першого ступеня.
- Halyna — сестра матері (тітка), 65 років; родичка другого ступеня.
- Andrii — син тітки Halyna (двоюрідний брат Oleny), 40 років; родич третього ступеня.
- Maria — бабуся по матері, померла; родичка другого ступеня.
- Імовірність успадкування тієї самої зміни: першого ступеня 0.5; другого 0.25; третього 0.125.
- Каскадне тестування CT-01 застосовується до Marta, Sofiia, Halyna, Andrii; для Sofiia тестування відкладено (вік < 18).

## Варіанти
- VAR-001: патогенний варіант (pathogenic variant) у гені BRCA1, SNP, germline; QD 25.0, FS 3.1, SOR 0.8, MQ 60.
- VAR-002: SNP у BRCA2, не патогенний (клінічне значення benign); QD 1.5 (менше 2 → прапорець LowQD).
- VAR-003: INDEL у BRCA2, FS 150.0 (поріг для INDEL FS > 200 → прапорця немає).
- VAR-004: SNP на кінці екзона (variant at exon end), FS 62.0 (> 60 → прапорець HighFS), SOR 2.1 (≤ 3).
Усі варіанти містяться у файлі sample1.vcf (VCF file), який отримано з sample1.bam (BAM file).

## Фільтрація
- Hard filtering run HF-01: застосовується до sample1.vcf; використовує показники QD, FS, SOR, MQ, MQRankSum, ReadPosRankSum.
- Пороги: QD < 2; FS > 60 (SNP); FS > 200 (INDEL); SOR > 3; MQ < 40; MQRankSum < −12.5; ReadPosRankSum < −8.
- Панель HBOC-panel містить гени BRCA1, BRCA2, PALB2, TP53 (мала панель → рекомендовано hard filtering, бо VQSR потребує великого набору варіантів і відомих ресурсів варіантів).
- Правило: будь-який прапорець → варіант FILTERED.
- Вік тестування: лише ≥ 18 років.
