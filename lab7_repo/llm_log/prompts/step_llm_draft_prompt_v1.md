# Підказка v1 для чернетки онтології (дослівно)

Ти — онтолог. Створи ЧЕРНЕТКУ OWL-онтології (Turtle) за вхідними матеріалами. Працюй самостійно; НЕ читай жодних інших каталогів, окрім вказаного нижче.

Вхід (прочитай усі файли) у каталозі `l7in/`:
- taxonomy_final.csv — таксономія (154 вузли; поля id,label,parent,definition,...);
- map_triples_v2.csv — триплети концептуальної карти (s,p,o,source,status,...), відношення з закритого каталогу: is_a, part_of, has_annotation, increases_risk_of, is_kin_of, uses_input, produces, applies_to, requires, recommended_for, detects, has_example;
- cq_lab4.md — компетентнісні запитання (CQ01–CQ18), які онтологія має вміти відповідати;
- scenario_facts.md — синтетичні факти, які треба закодувати як індивідів (екземпляри).

Вимоги до виходу:
1. Один файл Turtle: llm_draft.ttl (синтаксис має парситись rdflib; префікси оголоси).
2. owl:Ontology; ≥ 30 класів з ієрархією (rdfs:subClassOf), диз'юнктності там, де доречно, ≥ 3 аксіоми існування/універсальності (owl:someValuesFrom / allValuesFrom), ≥ 2 кардинальні обмеження; ≥ 10 об'єктних властивостей (≥ 2 з характеристиками: транзитивна/обернена/симетрична тощо) і ≥ 5 data-властивостей з domain/range.
3. Кожна сутність (клас, властивість, індивід) повинна мати rdfs:label@en. Для класів — англійський термін точно як у taxonomy_final.csv/map_triples_v2.csv (малими літерами, як там), для індивідів — імена з scenario_facts.md (Olena, VAR-001, HF-01, HBOC-panel тощо), для об'єктних властивостей — ідентифікатор відношення з каталогу, де є відповідне (requires, uses_input, applies_to, increases_risk_of, detects, produces, recommended_for, has_annotation, is_kin_of, part_of), для решти — коротка англійська мітка.
4. Закодуй у вигляді індивідів ВСІ факти з scenario_facts.md (особи, варіанти, показники, пороги, файли, панель, фільтрація, каскадне тестування, ймовірності, вік).
5. Додатково в окремий файл notes: llm_draft_notes.md — коротко: головні рішення моделювання (3–8 речень), без самооцінки якості.
Не використовуй мережу. Не вигадуй джерел. Після завершення відповідай одним реченням: скільки класів/властивостей/індивідів створено, і чи парситься файл.
