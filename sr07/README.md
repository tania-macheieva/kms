# Самостійна робота 7 — Помилки в онтологіях та шаблони ситуацій

## Завдання

Проаналізувати онтологію щонайменше з 50 класами, знайти й класифікувати помилки, виправити не менше трьох із демонстрацією наслідків та описати п'ять ситуацій шаблонами, пов'язаними з класами онтології.

## Файли та результати

- `ogms_old.owl`, `ogms_work.owl`, `ogms_fixed.owl` — онтологія до аналізу, робоча й виправлена версії.
- `reasoner_results.json`, `ontoclean_results.json`, `fix_log.json` — результати перевірок і журнал виправлень.
- `situation_templates.json` — п'ять шаблонів ситуацій.
- `SR7_ontology_errors.xlsx` — таблиці проблем, reasoner, перевірок, OntoClean, LLM та шаблонів.
- `code/` — скрипти перевірок і побудови результатів.

HermiT-порівняння та OntoClean-аналіз збережені. `pitfalls.py` — власний OOPS!-подібний скрипт, а не офіційний сервіс OOPS!; BFO у робочій копії представлене заглушками.

## Перебудова таблиці

Із PowerShell у цій папці:

```powershell
python -X utf8 code\build_xlsx.py
```

Для повторного запуску reasoner див. `code/reason_runs.py`; середовище має мати Owlready2 і Java/HermiT. Якщо курс вимагає саме OOPS!, запустіть офіційний сервіс і збережіть його висновки окремо. Формальний звіт DOCX/PDF не додається.
