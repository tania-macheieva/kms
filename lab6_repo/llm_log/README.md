# Журнал використання LLM
`log.csv` — крок, завдання, дата, модель, параметри (температура/seed недоступні), версія підказки, файл сирого виходу, рішення людини.
`raw/` — дослівні виходи; `prompts/` — тексти підказок і вхідних карт для оцінювачів. Рішення людини в усіх записах не зафіксовані.
Перевірка тверджень — `../claims/claims.csv`.
