| V2-07 | До карти додано 9 підтверджених триплетів LLM (цитата знайдена, типи коректні, ручний перегляд пройдено) | карта колеги й LLM показали пропущені в v1 зв'язки (mapping quality → sequencing read, VQSR → VCF file, genetic testing → рак тощо) | R1, R2; триплети L009–L040 |
