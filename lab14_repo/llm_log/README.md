# LLM-експерт: протокол (ЛР14)
Усі виклики LLM — офлайн-субагенти (ключа API немає), сліпі: анотатори й суддя не бачили оцінок схожості, золотих міток чи чужих відповідей.
Тут: `prompts/` (версії підказок), `in/` (вхід), `raw/` (сирий вихід моделі), `log.csv` (дата, модель, версія підказки, призначення, рішення людини).
Температура/seed не керуються. Кеш відповідей RAG: `../llm_cache/` (ключ sha256(модель|system|user)).
Обмеження: усі анотатори, суддя та «експерт» — LLM однієї родини; рішення «людини» ухвалив асистент, схвалення студента (V3) очікується.
Перед відновленням середовища була повна перша спроба ЛР14; її артефакти втрачено, усе перероблено наново — цифри цього репозиторію належать лише другій спробі.
