# Рівні верифікації тверджень (колонка `level`)
| Рівень | Значення |
|---|---|
| V1 | дослівна цитата знайдена в основному тексті джерела скриптом `scripts/verify_quotes.py` |
| V2 | цитата знайдена, але джерело другорядне (напр., коментар читача) |
| V3 | цитати немає (гіпотеза, синтез, припущення) або вона суперечить основному тексту |
| V4 | підтверджено незалежним джерелом чи експертом-людиною — **жодне твердження ще не має V4** |

Підсумок: 42 твердження; підтверджено 31 (74%); відхилено 4; pending 7. Джерела: GATK Team (Broad Institute), CDC Archive.
