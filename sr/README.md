## Перебудова табличних результатів

Звіти не створюються цими командами; де це передбачено роботою, скрипти формують таблиці та графіки. Запускайте з PowerShell із кодуванням UTF-8:

```powershell
cd sr\sr5
python -X utf8 build_out.py

cd ..\sr6
python -X utf8 build6.py
python -X utf8 draw.py

cd ..\sr7
python -X utf8 code\build_xlsx.py

cd ..\sr9\code
python -X utf8 build_sr9.py

cd ..\..\sr10
python -X utf8 src\build_sr10.py
```

Скрипти СР5, СР9 і СР10 також створюють DOCX. Для вимоги «без звітів» залишайте лише XLSX/графіки та видаляйте відповідні `SR5_report.docx`, `SR9_report.docx` і `SR10_report.docx` після запуску. СР8 запускається окремо за інструкціями у `sr8/README.md`. СР5 потребує відсутнього `so.obo` для повного повторного запуску `sr5.py`; СР10 для нового експерименту потребує ваг із `sr10/README_SR10.md`.
