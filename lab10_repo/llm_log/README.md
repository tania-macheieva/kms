# Журнал взаємодії з LLM (ЛР10)

Файл `log.csv`: дата, модель/версія, параметри (temperature і seed **не задавалися** — інтерфейс агентів не дає такої можливості; це обмеження відтворюваності), версія підказки, призначення, вхід, сирий вихід, рішення людини.

- `prompts/` — тексти підказок (gold_gen_v1, annot_b_v1).
- `in/` — вхідні дані, які бачила модель (gold_*.json, annot_b_items.json).
- `raw/` — сирі виходи моделі без правок (gold_single_out.json, gold_pairs_out.json, annot_b_out.json).

Усі виклики були «сліпими»: субагентам заборонено читати код, корпус поза вхідним файлом і розмітку інших розмітників. «Рішення людини» у цій роботі — це рішення рецензента-асистента (LLM) у сесії; студент мусить повторити перегляд (див. `claims/claims.csv`, статус pending).
Персональні дані зовнішнім сервісам не передавалися; у вході немає ключів, а власні звіти (синтетичні дані) обробляла лише сама модель сесії.
