# Самостійна робота 9 — Критерії порівняння графових баз

## Завдання

Порівняти Neo4j, GraphDB і Memgraph щонайменше за вісьмома критеріями, запустити п'ять запитів на тестових даних і обґрунтувати вибір сховища для заданого сценарію.

## Файли та результати

- `data/` — тестові сутності й зв'язки.
- `bench_results.json` — результати тестових запитів.
- `llm_eval_results.json`, `llm_sparql/` — оцінка та запити, створені LLM.
- `SR9_graph_db_comparison.xlsx` — таблиці вимірювань і порівняння.
- `code/` — генератор даних, бенчмарк і побудова таблиці.

Набір містить 600 вузлів і 2 910 ребер. П'ять запитів перевірено на Kuzu та Oxigraph; обидва рушії збігаються з незалежним Python-еталоном. Neo4j, GraphDB і Memgraph у бенчмарку не запускалися.

## Перебудова таблиці

Із PowerShell у цій папці:

```powershell
python -X utf8 code\build_sr9.py
```

Скрипт створює також `SR9_report.docx`. Формальний звіт DOCX/PDF до матеріалів не входить.
