# Протокол використання LLM (ЛР13)
- `prompts/` — версії промптів (annotate_v1/v2, adjudicate_v1, extract_v1/v2); `in/` — вхідні пакети; `raw/` — сирі відповіді моделей без правок; `log.csv` — журнал (дата, модель, температура/seed, версія промпту, сирий вивід, рішення).
- **Температуру й seed неможливо було задати**: моделі викликались як субагенти в середовищі без API-ключа; параметри — за замовчуванням постачальника. Відтворюваність забезпечує **replay-кеш** `llm_cache/cache.jsonl` (ключ = sha256(модель|system|user)): повторний запуск `src/extract_llm.py` бере відповіді з кешу.
- Реальний API-клієнт (`ANTHROPIC_API_KEY` лише зі змінної середовища) у `src/llm_client.py` **не перевірявся**.
- «Людське рішення» в журналі ухвалював LLM-асистент, що виконував роботу; студент не переглядав усе — статус V3 не присвоєно (див. `claims/claims.csv`, pending).
- Анотатори (sonnet) ≠ екстрактор (haiku), але це одна родина моделей.
