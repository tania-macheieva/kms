# claims.csv — реєстр тверджень (ЛР13)
Рівні: V1 — цитата в джерелі (автоперевірка дослівності); V2 — схема/типи/правило; V4 — метрики P/R/F1, відтворюються скриптами. Статус: verified / rejected / pending (pending = потребує перевірки студентом; V3 не присвоювався).
Частку підтверджених і пояснення відхилених див. у звіті (розділ «Протокол»), числа — `python scripts/claims_summary.py`.
