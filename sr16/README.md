# Самостійна робота 16 — Оцінювання рекомендаційної системи

## Експеримент

Використано часовий поділ MovieLens: взаємодії до 80-го перцентиля часу — навчальна вибірка, пізніші — тестова. Оцінюються теплі користувачі з щонайменше трьома позитивними оцінками в train; у прогоні 3 129 користувачів, випадкова відтворювана підвибірка — до 6 000. Каталог обмежено фільмами до 2018 року; код трактує оцінку `r >= 8` як позитивну взаємодію.

## Основні результати

| Підхід | Precision@5 | nDCG@10 | Coverage@10 | Novelty |
|---|---:|---:|---:|---:|
| Популярність | 0.0095 | 0.0130 | 0.19% | 4.82 |
| Content-based (жанр + десятиліття) | 0.0009 | 0.0013 | 21.34% | 13.45 |
| SVD embedding (k=64) | 0.0145 | 0.0212 | 1.05% | 6.33 |
| Граф P3 random walk | 0.0114 | 0.0165 | 2.94% | 5.49 |
| Гібрид SVD + content + popularity | 0.0148 | 0.0206 | 1.03% | 6.30 |

Це результати з `results.json`; `charts.png` показує точність/покриття, холодний старт користувача та компроміс точності з різноманіттям. Файл також містить порівняння часової та випадкової вибірок, парні інтервали довіри й штраф популярності.

## Холодний старт і обмеження

У сценарії холодного старту користувача перевірено 1 230 нових користувачів; Precision@5 при п'яти початкових взаємодіях становить 0.0250 для popularity, 0.0044 для content-based, 0.0426 для SVD, 0.0415 для графа та 0.0437 для гібриду. Без профілю використовується popularity fallback. Окремо тест містить 3 038 холодних товарів; їхня частка серед позитивних тестових взаємодій — 22.35%. У збереженому прогоні content-based має Precision@5 0.0105 для цієї підмножини. Значення для Popularity і SVD у старому блоці `cold_items` обчислені некоректною попередньою версією оцінювача й не використовуються як висновок. Код `run.py` виправлено для модельно-специфічного розрахунку, але повторний прогін ще не виконаний: локальних `data/ratings.dat` і `data/movies.dat` немає.

## Етичні аспекти

- Популярнісне упередження: у popularity верхній 1% каталогу отримав 100% рекомендацій; novelty низька (4.82). Контроль — відстеження концентрації, novelty та Gini.
- Низьке охоплення й різноманіття у SVD: coverage 1.05% проти 21.34% у content-based. Контроль — перевірка coverage/ILD і порівняння компромісу з точністю.
- Приватність історії взаємодій: профіль рейтингових даних може розкривати вподобання. Контроль — мінімізація та псевдонімізація історії, обмеження строку зберігання й доступу.

## Файли та відтворення

- `run.py` — часовий split, популярнісний, контентний, SVD, P3-графовий і гібридний методи; cold-start та метрики.
- `results.json`, `run.log` — збережені результати й лог попереднього прогону.
- `charts.py`, `charts.png` — графіки за `results.json`.

Потрібні `numpy`, `pandas`, `scipy`, `matplotlib` та локальні MovieLens-файли. Із PowerShell у цій папці після розміщення вхідних даних у `data/`:

```powershell
python -X utf8 run.py
python -X utf8 charts.py
```

Для альтернативних шляхів до даних і вихідного JSON доступні параметри `--ratings`, `--movies` та `--out`.
