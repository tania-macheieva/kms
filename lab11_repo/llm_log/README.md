# Журнал взаємодії з LLM (ЛР11)

`log.csv`: дата, модель/версія, параметри (temperature і seed **не задавалися** — інтерфейс агентів не дає такої можливості; це обмеження відтворюваності), версія підказки, призначення, вхід, сирий вихід, рішення людини.

- `prompts/` — `gen_protocol_v1.txt` (протокол офлайн-генерації), `judge_v1.txt` (рубрика судді); системна підказка бота — `../prompts/rag_v1.md`.
- `in/` — вхід, який бачила модель (`gen_*.json`, `judge_*_part*.json`); `raw/` — сирі виходи без правок.
- Генератор = `claude-haiku-4-5-20251001`, суддя = `claude-sonnet-5-5` (інша модель). Виклики «сліпі»: субагенти читали лише протокол і вхідний файл.
- Відповіді генератора відтворюються з хеш-кешу `data/llm_cache/` (ключ = sha256(модель|system|user)), тому всі метрики репозиторію відтворюються без мережі й ключів.
- «Рішення людини» — рішення LLM-рецензента сесії (не генератор і не суддя); студент мусить повторити перегляд (див. `claims/claims.csv`, `eval/manual_checks.json`).
- Персональних даних зовнішнім сервісам не передавалося (дані синтетичні), ключів у входах немає.
- Обмеження: затримка пакетних викликів не відображає реальну затримку API; вартість у звіті — модельна.
