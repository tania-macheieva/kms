# Таблиця тверджень (ЛР11)

`claims.csv`: id, твердження, тип (факт/правило/гіпотеза), джерело, рівень верифікації, статус, коментар.
Рівні: V1 — джерело/цитата; V3 — суддя + людина; V4 — метрики/тести.

Усього 24 тверджень: **verified 14 (58%)**, rejected 3 (12%), pending 7 (29%).
Відхилені: C09, C10, C11 — пояснення в колонці comment (твердження генератора, яких немає в контексті/цитованому фрагменті).
«Людський» перегляд виконав LLM-рецензент сесії (не генератор і не суддя), тому для V3 студент мусить повторити перевірку; pending — те, що не підтверджено або є припущенням (ціни, модель затримки, слабка статистична сила).
