# Реєстр тверджень (claims.csv)

Поля: `id, claim, type (fact/rule/hypothesis), source, level (V1–V4), status (verified/rejected/pending), comment`.

Рівні перевірки: **V1** — поверхнева (збіг заголовка / одне джерело), **V2** — повторне обчислення або автоматичний тест іншим способом, **V3** — незалежна людина-експерт, **V4** — незалежна вибірка/метрика на еталонах, складених не автором. Рівнів V3 і V4 у цій роботі **не досягнуто** (еталони й перевірки створено тією самою системою, що й генерація); вимога завдання «V4 для метрик на ≥15 питаннях» виконана лише формально — метрики обчислені на 24 питаннях, але чесна оцінка їхнього рівня — V2.

Частки (24 твердження): verified — 16 (67%), pending — 5 (21%), rejected — 3 (12%).
Відхилені: C18 (Fuseki не використано), C19 (справжня Wikidata не опитана), C24 (дані не реальні). Відкриті (pending): C13, C16, C17, C22, C23.
