# Рівні верифікації тверджень (колонка `level`)
| Рівень | Значення |
|---|---|
| V1 | перевірено за зовнішнім джерелом або відтворюваним обчисленням (MeSH Lookup API, підрахунок, метрика) |
| V2 | перевірено автоматичними тестами структури (pytest) |
| V3 | лише LLM / міркування без зовнішньої перевірки |
| V4 | підтверджено експертом-людиною — **жодне твердження ще не має V4** |

(https://www.w3.org/TR/skos-reference/), GATK Team і CDC Archive (тексти з ЛР4, лише для частот термінів), spaCy en_core_web_md 3.8.0.
