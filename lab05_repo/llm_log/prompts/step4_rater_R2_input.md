# Категорії (вибери РІВНО одну для кожного терміна)

- **Biological entity** — Біологічна сутність: елемент геному або білкова сутність (ген, хромосома, білок, пептид тощо).
- **Genetic variation** — Генетична варіація: типи варіантів, їхнє походження та клінічна значущість.
- **Biological property** — Біологічна властивість або процес: спадковість (генотип, фенотип, пенетрантність) та молекулярна активність (експресія, метилювання, PTM).
- **Method and procedure** — Метод або процедура: лабораторні методи, обчислювальні кроки обробки, клінічні процедури, наукові дисципліни.
- **Data and artifact** — Дані й артефакти: файли й записи (ріди, VCF, EHR), клінічні дані, метадані.
- **Measure of quality** — Міра якості: анотації якості варіантів (QD, FS, SOR, MQ…) та якість даних.
- **Clinical concept** — Клінічне поняття: особа (пацієнт, родич), стан (діагноз, хвороба, симптом), терапевтичний засіб, етичні гарантії.
- **Knowledge and information technology** — Знання та ІТ: системи організації знань, ресурси даних, бази даних, стандарти подання, інженерія знань.
