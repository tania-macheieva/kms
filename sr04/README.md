# Самостійна робота 4 — Продукційні правила для діагностики

## Завдання

Створити не менше 20 правил IF–THEN із джерелами, проаналізувати дублікати, надлишкові, конфліктні й недосяжні правила, обрати стратегію розв’язання конфліктів і порівняти її на 10 тестових ситуаціях до та після виправлень.

## Файли та результати

- `rules_draft.json` — початкові 28 правил.
- `rules_fixed.json` — виправлена версія з 23 правилами.
- `analysis.json` — аналіз правил і результати десяти тестів.
- `sr4.py` — рушій, аналізатор і генератор файлів.

Збережений прогін показує 6/10 успішних тестів до змін і 10/10 після. Аналіз виявляє дублікати, надлишковість, конфлікти та недосяжне правило.

## Запуск

З PowerShell у цій папці:

```powershell
python -X utf8 sr4.py
```

Зовнішні залежності не потрібні. Запуск перезаписує JSON-файли результатів.

**Перед здачею:** якщо використовувався генеративний ШІ, додайте правдиву декларацію з моделлю, прикладом запиту та способом перевірки. Формальний звіт DOCX/PDF не додається.
