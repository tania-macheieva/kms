## Файли

- `kms_quality.py` — розрахунок M1–M8.
- `remediate.py` — створення очищеної копії `data_s2/` та журнал змін.
- `test_mutations.py` — тести чутливості метрик до дефектів.
- `thresholds.json`, `thresholds_fixed_at.txt` — сценарні пороги та час їх фіксації.
- `snap/s1.json`, `snap/s2.json`, `snap/remediation_log.json`, `snap/mutation_tests.json` — результати.
- `dashboard.py` — побудова діаграми.

## Повторний запуск

Із PowerShell у цій папці:

```powershell
python -X utf8 kms_quality.py --data data --as-of 2026-11-12 --out snap/s1.json
python -X utf8 remediate.py
python -X utf8 kms_quality.py --data data_s2 --as-of 2026-11-12 --out snap/s2.json
python -X utf8 test_mutations.py
python -X utf8 dashboard.py
```

Метрики використовують стандартну бібліотеку Python; для діаграми потрібен `matplotlib`. `remediate.py` перебудовує каталог `data_s2/` із `data/`.
